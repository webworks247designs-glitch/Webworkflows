## Data Flow

### 1. Primary Visitor Conversion Flow
1. Visitor lands on `webworkflos.com` (rendered by Next.js Server & Client Components).
2. Visitor explores WorkDeck, Case Study (+310% salon growth), and Pricing (₹3,000 launch).
3. Visitor clicks any **WhatsApp CTA**:
   - `analytics.ts` builds an encoded URL targeting `+91 99598 96378` (Founder Srishanth M.).
   - WhatsApp opens directly on the user's phone or desktop with pre-filled context (e.g. Free Growth Plan, Inquiry, or Custom Rate).

### 2. Conversational Lead Qualification via Meera AI
1. Visitor asks a question in the chat card or clicks a suggestion chip (English, Telugu, or Hindi).
2. [src/components/MeeraAssistant.tsx](file:///Users/mkeerthana/Documents/Work/website/src/components/MeeraAssistant.tsx) queries the grounded store:
   - `queryKnowledgeBase(text, lang)` tokenizes input and scores keywords against 14 grounded business topics.
   - If match is found, returns verified, factual copy regarding pricing, hosting, or verification.
3. If visitor asks for a call or growth plan:
   - Form modal collects Name, Mobile Number, Business Name, Preferred Time.
   - Dispatches `POST /api/arrange-call` which formats lead dossier and outputs direct Founder WhatsApp URL.

### 3. Outbound AI Telephony Flow (Bolna AI)
1. User requests an immediate telephone callback via `/api/call-request`.
2. Handler checks IST business hours (9:00 AM – 9:00 PM).
3. If active credentials exist, POSTs to `https://api.bolna.dev/call` with Agent ID and Recipient Number.
4. Bolna calls client device; on call completion, Bolna sends webhook event to `/api/webhooks/bolna` recording call summary and audio recording URL.

## Conventions

### Naming
- **Components:** PascalCase (e.g., `MeeraAssistant.tsx`, `PricingVerification.tsx`).
- **Utilities & Helpers:** camelCase (e.g., `voiceUtils.ts`, `analytics.ts`).
- **API Routes:** Next.js App Router route convention (`src/app/api/<route-name>/route.ts`).
- **Knowledge Base IDs:** kebab-case (e.g., `pricing-model-clarification`, `free-growth-plan`).

### Structure
- **App Router:** `src/app/` handles page layout, fonts, metadata, global styles, and API routes.
- **Components:** Flat structure in `src/components/` containing both active and legacy components.
- **Styling Architecture:**
